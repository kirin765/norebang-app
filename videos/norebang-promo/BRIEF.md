# 노래방 번호검색 — 앱 홍보영상 (뒤에 붙일 promo 파트)

## Intent
사용자가 "앞에는 실제 노래방 장면, 뒤에는 앱 홍보영상"을 이어붙일 계획.
이 프로젝트는 **뒤에 붙일 앱 홍보 파트만** 제작한다.
앵글: 노래방에서 "이 곡 번호 뭐였지?" 헤매는 페인 → 앱으로 3초 검색 → TJ·금영 13만곡 오프라인 → 즐겨찾기 → 다운로드 CTA.

## Product
- 앱 이름: **노래방 번호검색** (com.happylife2080.norebang, 네이티브 Kotlin/Compose)
- 핵심: TJ·금영(KY) 노래방 곡 번호를 곡명/가수명으로 검색. 13만곡 오프라인 DB 번들 — 인터넷 없이 빠른 검색.
- 즐겨찾기(하트)로 자주 부르는 곡 저장.
- 브랜드 컬러: primary 퍼플 #5B2EFF, TJ 블루 #2E7DFF, 금영 레드 #E5484D. 배경 #FCFBFF.

## Customizations
- 무음 (music: none, 내레이션 없음) — 앞 실제 장면의 음악/노래 소리를 이어가거나 사용자가 편집기에서 음악을 얹을 수 있도록. 강한 한글 키네틱 타이포가 메시지를 전달.
- **금지 문구:** "광고없음" (차후 AdMob 배너 예정이라 제외).
- 폰 목업 안에 앱 검색 UI(검색바 + TJ/금영 필터칩 + 곡 결과 리스트 + 즐겨찾기 하트) 재현.
