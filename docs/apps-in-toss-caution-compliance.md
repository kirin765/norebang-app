# 앱인토스 제출 주의사항/컴플라이언스 — 노래방 번호검색

## 1. 앱인토스는 UI 스타일이 아니라 플랫폼이다

앱인토스(App in Toss)는 **토스 앱 안에 기존 웹 앱을 미니앱으로 게시**하는
플랫폼이다. 노래방 번호검색의 기존 디자인(브랜드 보라 `#5B2EFF`, 한국어 UI)을
그대로 유지한다. "토스 핀테크 스타일"(흰색/`#3182F6`)로 리스타일하지 않는다.

## 2. 한국어 UI 유지 (필수)

- `index.html` → `lang="ko"` ✅
- PWA `manifest.webmanifest` → `lang: "ko"` ✅
- 모든 메뉴·버튼·사용자 대상 문구 한국어 ✅ (검색, 전체/TJ/금영, 즐겨찾기 등)
- 스크린샷 자산 역시 한국어 UI 상태로 캡처 ✅

## 3. 앱 이름 / appName

| 항목 | 규칙 | 적용 |
|---|---|---|
| 한국어 이름 | ≤10자 · 추후 수정 가능 | `노래방 번호검색` (7자) |
| 영어 이름 | ≤15자 · 명사 · 명령형 금지 | `Noraebang` (9자) |
| appName | 고유 ID · **등록 후 불변** · 콘솔=config 일치 | `norebang-number` ✅ (bundle.json 검증 완료) |
| 딥링크 | `intoss://norebang-number` | 콘솔 등록 시 결정 |

- appName은 `apps-in-toss.config.ts`와 콘솔 등록 값이 **정확히 일치**해야 한다.
- 등록 후 appName 변경은 **불가** — 등록 전에 신중히 확정할 것.

## 4. 게임/비게임 판정

- 본 앱은 **비게임** (게임머니·베팅·결제 없음, 검색 유틸리티)
- GRAC 등급분류 **불필요** — `docs/grac/README.md` 근거 참조
- 웹보드(체스/장기/오목 등) 아님 → 스토어 링크 제약 없음
- 게임 유형으로 바꾸면 GRAC 심의 + 등급분류증명서가 필수로 부활한다 (절대
  스토어 IARC로 대체 불가 — 한국에서 유효하지 않음)

## 5. 개인정보/권한

- `permissions: []` — 클립보드·위치·연락처·사진·카메라·마이크 **none**
- 즐겨찾기는 브라우저 `localStorage`에만 저장 (서버 전송 없음)
- 곡 DB는 앱 번들 `songs.json` (130,599곡, 2026-06-11) — 외부 전송 없음
- 원곡 음원/가사 미포함 — 곡명·가수명·반주기 번호 메타데이터만 제공

## 6. 백엔드/CORS

백엔드 없음 → CORS 설정 불필요. 서버 연동 추가 시:
`https://norebang-number.web.tossmini.com` +
`https://norebang-number.private-web.tossmini.com` 허용 필요.

## 7. 출시 전 체크리스트

## 8. 금지사항 요약

- ❌ 앱 UI를 토스 핀테크 스타일로 변경
- ❌ 게임 유형인데 GRAC 코드/증명서 생략 (현재 비게임이라 해당 없음)
- ❌ 콘솔 등록 후 appName 변경
- ❌ 웹보드 게임에 스토어 링크 경로 사용 (현재 해당 없음)
- ❌ 앱 UI 영어화 (한국어 유지)
