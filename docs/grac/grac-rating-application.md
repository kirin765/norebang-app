# GRAC 게임 등급분류 심의 신청 절차 (참고 — 비게임 앱에는 해당 없음)

> ⚠️ **노래방 번호검색은 비게임 앱**이므로 이 절차는 현재 **필요 없다.**
> 다만 앱이 '게임' 유형으로 전환될 때를 대비해 보존한다.
>
> 사전 판단: 리듬 게임·퀴즈 게임 등으로 기능을 추가해 '게임' 유형으로
> 등록하려는 경우에만 필요하다. 게임 유형 = GRAC 등급분류 필수.

## 절차 요약 (전환 시)

1. [게임물관리위원회(GRAC)](https://www.grac.or.kr) 로그인 — 개인사업자/개인 모두 가입
2. **[등급분류신청] → [오픈마켓/등급분류 신청]**
   - 플랫폼: 모바일 게임 · 스토어명: 기타-앱인토스
3. 네트워크 접속: 인터넷 접속 / 수익·과금·유통 방식 입력 (무료·광고 없음)
4. 내용정보 작성: 선정성·폭력성·약물·언어·사행성 — 노래방 검색 특성상
   '해당 없음' 수준 예상
5. 첨부: 게임물내용설명서 + 실행 가능한 게임물(웹 번들 `dist/`) + 심의용
   플레이 영상
6. **간소화 신청** 가능 여부 확인 (청소년이용가 범위 게임은 간소화 신청 대상 —
   수수료·기간 절감; 개인 제작 게임 50% 할인)
7. 심의 수수료 입금 → 신청 완료 → **등급분류증명서 PDF 발급** (약 10~15일)
8. 콘솔 게임 등급분류 단계에서 증명서 PDF 첨부
   (`console-rating-checklist.md` B절 참조)

## 수수료 계산 (모바일 기준, 2026-08-23)

| 항목 | 값 |
|---|---|
| 기본 수수료 (오픈마켓 제외 모바일) | 60,000 KRW |
| 장르 계수 (보드 3군) | ×1.5 → 보드게임 90,000 KRW (비보드 게임은 장르별 상이) |
| 비네트워크 | ×1.0 |
| 한국어 | ×1.0 |
| **개인 제작 50% 할인** | 보드 예: 45,000 KRW |

> 노래방 검색 앱 특성상 게임 전환 시에도 보드 3군이 아닌 단순 리듬/퀴즈
> 장르로 분류될 가능성이 높아 위 금액은 참고용이다.
