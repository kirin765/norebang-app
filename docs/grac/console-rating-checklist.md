# 앱인토스 콘솔 등급 입력 체크리스트 (노래방 번호검색 — 비게임)

> **2026-08-23 판정: 비게임 앱** — 노래방 곡 번호 검색 유틸리티로
> 게임물관리위원회(GRAC) 등급분류 **대상 아님**. 아래는 (1) 현재 상태의 콘솔
> 처리와 (2) 만약 게임 유형으로 전환된다면 필요한 절차를 함께 정리한다.

---

## A. 현재 (비게임) — 콘솔 이용등급 처리

1. 콘솔 → 앱 정보 → **앱 유형: 비게임** 선택
2. **접근 연령(이용등급): 전체이용가** 선택
   - 게임 등급분류 단계는 비게임에는 표시되지 않음 → GRAC 서류 불필요
3. 자체등급분류 게임물 정보 입력란 없음 (비게임)
4. 등록자명/사업자명 불일치 이슈 해당 없음

## B. 게임 유형 전환 시 (대비용) — GRAC 증명서 경로

비게임 → 게임 재분류 시 **스토어 링크(구글 플레이 자체등급분류/IARC) 경로는
웹보드류(체스·장기·오목 등)가 아니어도 게임 유형이면 GRAC 등급분류 증명서
PDF가 원칙**이다. 절차:

1. **GRAC 조회 먼저**: `python3 docs/grac/query-grac.py "게임명"`
   - 등급분류번호가 이미 있으면 3번으로
   - 0건이면 → 2번
2. GRAC 심의 신청 (10~15일) → `grac-rating-application.md` 절차
   - 청소년이용가 범위 게임은 '간소화 신청' 가능, 개인 제작 50% 할인
3. 콘솔 → 게임 등급분류:
   - **게임 등급 정보**: 게임물 등급분류증명서(PDF) 첨부
   - **자체등급분류 게임물 정보**: 등록자명 · 등급분류일자 · **등급분류번호** ·
     이용등급 · 내용정보 — 증명서와 **문자 그대로 일치**해야 함
   - 게임 화면 첨부: 플레이 화면 원본 2장+2장 (편집 금지)

## 등급분류번호 포맷 (실측, 2026-08-23)

| 코드 예 | 시리즈 |
|---|---|
| `GC-CC-NP-YYMMDD-###` | 정식 등급분류 |
| `SC-OM-YYMMDD-###` | 오픈마켓 자체등급분류 |
| `CC-NP-YYMMDD-###` | 구형 포맷 |

`YYMMDD` = 등급분류일자, `###` = 일련번호.
